# Titanic Data Cleaning and Exploratory Data Analysis (EDA)

## Objective
The objective of this project is to perform Data Cleaning and Exploratory Data Analysis (EDA) on the Titanic dataset. The project identifies patterns, trends, and relationships between different variables affecting passenger survival.

## Dataset
- Titanic Dataset
- Source: Kaggle

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Steps Performed
1. Loaded the dataset.
2. Checked dataset information.
3. Identified missing values.
4. Filled missing values in Age using the median.
5. Filled missing values in Embarked using the mode.
6. Removed the Cabin column due to excessive missing values.
7. Checked for duplicate records.
8. Performed Exploratory Data Analysis (EDA).
9. Visualized relationships between variables.
10. Saved the cleaned dataset.

## Visualizations
- Survival Count
- Survival by Gender
- Survival by Passenger Class
- Age Distribution
- Fare Distribution
- Correlation Heatmap

## Key Findings
- Female passengers had a higher survival rate than male passengers.
- First-class passengers were more likely to survive.
- Most passengers were between 20 and 40 years old.
- Higher ticket fares were associated with higher survival.
- The cleaned dataset is ready for further analysis or machine learning.
